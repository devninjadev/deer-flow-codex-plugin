# DeerFlow Skills — Codex용 비공식 플러그인

이 저장소는 [ByteDance의 공식 DeerFlow 저장소](https://github.com/bytedance/deer-flow)를 devninjadev가 포크한 곳입니다. DeerFlow의 공개 스킬을 **OpenAI Codex**에서 사용할 수 있도록 플러그인으로 묶었습니다.

## [한국어 사용자 매뉴얼 열기](MANUAL.ko.md)

공개 스킬 23개의 사용법과 Codex에 복사해 쓸 수 있는 요청 예시를 담았습니다.

플러그인을 설치하면 Codex 대화에서 논문 검토, 문헌 조사, 데이터 시각화, 발표 자료 작성 같은 작업에 해당 스킬을 사용할 수 있습니다. 어떤 작업부터 시작할지 궁금하면 “DeerFlow 사용자 매뉴얼을 열어줘”라고 입력하세요.
