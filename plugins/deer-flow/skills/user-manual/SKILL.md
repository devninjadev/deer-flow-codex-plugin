# DeerFlow 사용자 매뉴얼 열기

Use the installed copy of `assets/manual.ko.html` relative to this SKILL.md. Resolve its absolute path from this skill’s location. When asked to open the guide, open that file in the available browser or desktop viewer and return a clickable local file link labeled “DeerFlow 사용자 매뉴얼”. If opening the viewer is unavailable, provide the file link directly. The manual is bundled and works offline.
