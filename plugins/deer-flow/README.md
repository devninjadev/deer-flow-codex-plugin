# DeerFlow Skills for Codex

This directory packages the DeerFlow public skills for Codex. The marketplace entry at `.agents/plugins/marketplace.json` points here. Version 1.0.2 bundles skills from [upstream revision 585abb9](https://github.com/bytedance/deer-flow/tree/585abb979fbc483485c0fc53ed0e571ab7eebadb/skills/public) along with local additions.
